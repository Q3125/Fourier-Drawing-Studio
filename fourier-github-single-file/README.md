# 转迹 · 傅里叶绘画实验室

单文件网页小程序：样式、算法、界面和字体均已内嵌在 `index.html`，不需要安装依赖或联网加载资源。直接双击打开即可使用，推荐新版 Chrome / Edge。

## 使用

- 上传 PNG、JPG、WebP 或 SVG，支持多张图片逐张选择。
- 自动提取线条，默认保留精细轮廓，可调整识别方式、阈值与碎线过滤。
- 每张图片使用一个全局傅里叶函数，通过旋转矢量绘画；分离线条之间抬笔。
- “高清完成图”导出 3072×3072 PNG。
- “录制绘画过程”生成 1080p 视频预览，按需点击下载或丢弃。支持浏览器可用的 MP4 / WebM。

所有图片只在浏览器内处理，不上传服务器；刷新后需重新选择图片。每张图片不超过 20 MB。图像提取属于近似轮廓识别，不包含语义主体识别。自动重建误差目标为 0.35 个处理图像像素；密集图像的采样数最多 262144。实际录制帧率受设备影响，录制时保持页面在前台。

程序本身只需要 `index.html`；另外两份文件提供说明和字体授权信息。不要只把 ZIP 上传到仓库后期待它直接成为网页，应先解压上传里面的文件。

字体使用 Noto Serif SC 的子集，授权正文同时保留在 HTML 中及 `FONT-LICENSE.txt`。

可分别自定义绘画线条和矢量箭头颜色，已画轨迹、旋转圆和图例会同步更新；图片及视频导出使用所选颜色。支持恢复默认配色。

手绘画板支持鼠标、触控笔和手指自由画线，可调笔画粗细、撤销上一笔及清空。点击“用傅里叶绘制”将当前作品加入图片列表，使用线稿中心线提取及同一个全局傅里叶函数绘画，可继续导出高清图片与视频。画板草稿在关闭后保留于本页，刷新会清空。
