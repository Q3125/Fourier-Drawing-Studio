为什么旋转可以画图？

把轮廓上的每个点写成复数 z(t) = x(t) + iy(t)，离散傅里叶变换就能把这条路径分解成不同频率、振幅和初始角度的旋转矢量。将它们首尾相接，最后一个箭头的尖端就是画笔。

z(t) ≈ Σ cₖ ei2πkt

上传图片后，程序先做平滑、边缘检测和线条细化，再过滤短线并排序轮廓。不同轮廓之间会抬笔移动。采样点经过快速傅里叶变换，按振幅选择最显著的矢量进行绘画。

自动判断会识别均匀背景上的线稿，包括浅色、反色和彩色线条；照片则提取亮度与颜色边缘。也可手动选择识别方式。精细模式保留更多小线条，采样密度随整张图的轮廓长度自动增加，最多 262144 点。自动保真模式按轮廓坐标的最大偏差选择傅里叶项，保留眼睛、发丝与衣褶等细节。整张图共享一个函数 z(t)，抬笔时只改变是否留下轨迹，不切换函数。

线稿、图标和对比鲜明的图形效果最佳。照片的纹理与背景也可能被识别为边缘，调整“边缘阈值”和“去除碎线”可突出主体。提取结果是近似轮廓，不是语义识别；减少矢量会使轮廓更圆润。

支持批量上传并切换图片。图片不会上传到服务器；刷新后需重新选择本地图片。视频从空白开始画完整张图片，最后停留 1 秒后结束录制。录制完成仅生成预览，点击“下载视频”才会保存，也可丢弃重录。视频直接以 1920 × 1080 绘制，高清完成图为 3072 × 3072，采集目标 60 帧／秒，优先使用 MP4，也可选择 WebM；实际格式支持和帧率由设备与浏览器决定，建议在 Chrome 或 Edge 中使用。
